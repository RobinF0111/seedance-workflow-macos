# sd提示词WIP skill

把剧情、分镜、参考素材或已有提示词整理成可直接提交的中文 Seedance Prompt。保持剧情事实不变，重点提高人物表演、空间关系、影视级运镜和剪辑连续性。

## 工作原则

1. 保留人物身份与数量、关系、场景、天气、道具、事件顺序、台词原文和故事结果。
2. 不编造对白、人物关系、素材编号、品牌、时间段或剧情结果。
3. 把内心活动转成可观察行为，不用情绪形容词替代表演。
4. 默认输出一个最佳版本；用户明确要求对比时才输出多个。
5. 只输出可提交的 Prompt 正文，不输出分析、说明或代码围栏。
6. 总时长、画幅、帧率、分辨率等页面参数不写入 Prompt；用户原有的剧情时间段可以保留。

## 固定输出结构

严格按以下顺序输出：

```text
【画质+影像风格限定】
【光影】
【人物与场景参考】
【场景+主要情节】
【镜头1：机器型号+镜头+焦段+光圈+景别+角度+镜头拍摄风格+运镜手法】：情节、人物动作、微表情、情绪、声音与完整运镜描述
【镜头2：机器型号+镜头+焦段+光圈+景别+角度+镜头拍摄风格+运镜手法】：……
【表演与剪辑连续性限定】
【反向限定】
```

镜头数量由剧情决定，不为填满格式增加无叙事作用的切镜。

每个镜头标题必须包含一个明确景别，不得只写焦段或“关系镜头”。景别从大全景、全景、中全景、中景、中近景、近景、特写、大特写中选择最准确的一项；双人或群像镜头可写“双人中景”“双人近景”或“群像全景”。

每个镜头正文必须以以下格式开头：

```text
起幅：<一句简洁、可直接看见的画面caption>（<起幅景别>）。
前景：<一个明确对象或“无明显前景遮挡”>；后景：<一个明确环境、人物或叙事对象>。
```

起幅 caption 只描述画面开始瞬间已经存在的主体、动作状态、画面位置和人物关系，不在其中解释心理、因果、后续动作、运镜路径或摄影目的。优先控制在一个短句内。标题中的景别与起幅景别原则上保持一致；确有景别变化时，标题写主导景别，并在正文明确变化边界。

## 编译流程

### 1. 建立故事合同

锁定人物与关系、场景与天气、事件因果、台词及说话人、关键道具与归属、开始和结束状态，以及用户指定的镜头、声音和排除项。

对白使用 `{}`，音效使用 `<>`，音乐使用 `()`。无字幕时明确“无字幕”。不得扩写用户只提供的台词片段。

### 2. 映射参考素材

在【人物与场景参考】中只写真实存在的素材职责，不写剧情和动作：

```text
人物A对应@角色1，只采用五官、发型、服装与体态。
@角色2用于补充人物A的面部细节，与@角色1共同定义同一人物，不生成第二个副本。
人物B对应@角色3，只采用外貌与服装。
@参考图1用于场景空间、材质与天气，不采用图中无关人物。
@音频1用于人物A的音色与说话方式，不改变台词原文。
```

不同人物逐条映射。不能访问素材时，不声称看过素材，只保留用户明确指定的职责。

延长视频时写明：从原视频末帧继续，只向后生成；继承人物位置、姿态、接触关系、道具状态、场景、光线、运动趋势、摄影轴线与声音状态，不改写原片段。

### 3. 压缩场景摘要

【场景+主要情节】只用一段说明本场发生什么、人物关系或情绪怎样变化、希望观众感受到什么。不要重复逐镜动作、台词、摄影参数或素材映射。

### 4. 设计人物表演

为主要人物建立可观察的行为动机链：

```text
前置身体与情绪状态
→ 当前目标
→ 阻碍或压抑
→ 外部触发
→ 短暂判断
→ 行为选择
→ 对方反馈
→ 关系或情绪变化
→ 台词后的情绪残留
```

每个抽象动机至少对应一个可见表现，如视线、呼吸、吞咽、手指停顿、重心变化、接触力度或动作延迟。每个镜头只选两至四个主要表演节拍，节拍之间保留自然停顿。

禁止用“突然悲伤”“眼神瞬间狠戾”替代变化过程。情绪转折按“即时身体反应—短暂停顿—主动压制或选择—稳定后的新状态”展开。

多人场景同时写主要人物和关系人物的反馈，通过靠近、退让、扶持、松手、视线确认、闭口聆听或接触力度呈现关系变化。

### 5. 设计关系构图

每个镜头只使用两个空间层级字段：

- **前景**：人物局部、肩背、门框、树枝、护栏、缆绳、道具或其他合理遮挡；没有明确前景时写“无明显前景遮挡”。
- **后景**：场景纵深、关系人物、环境运动、道路、建筑、海面或叙事声源。

不要再使用“中景是什么”作为空间方位描述。`中景`只保留为人物景别类型，与前景、后景的空间层级概念分开。主要人物、动作和人物关系直接写入起幅 caption 与后续表演描述。

即使只有一个人物，也保留其与道具、道路、门口、车辆、海面或声源的关系。减少连续的孤立面部特写和纯道具插入镜头。前景不能遮住关键动作或全部面部；后景关系人物可以虚化，但须能辨认姿态、视线或反馈。

### 6. 设计有动机的影视级运镜

先读取输入中的剧情类型、情绪曲线、节奏、视觉风格、人物运动和空间规模，再选择运镜。选择优先级固定为：

```text
用户明确指定
→ 剧情功能与情绪氛围
→ 人物运动和空间关系
→ 视觉风格
→ 连续性与可执行性
→ 技巧的新奇程度
```

不得因为参考库中存在某种手法就强行使用。没有特殊叙事需求时，使用基础的关系型运镜或固定观察，不添加炫技镜头。一个镜头通常只使用一种主要运镜；高辨识度特殊手法原则上只用于一个明确的戏剧节点。

镜头运动必须来自环境、情绪、氛围或人物运动，不能只为改变景别而运动：

```text
环境或人物触发
→ 人物先反应或行动
→ 镜头延迟半拍响应
→ 小幅、低速、单一方向运动
→ 人物稳定后镜头缓慢落幅
```

根据剧情从以下运镜库中选择：

- **缓慢推进（Slow Push-in / Dolly In）**：适合注意力收束、秘密逼近、压抑加深、人物逐渐做出决定；从环境或关系景别平稳靠近，但短镜头内不得直接由全景冲到特写。
- **缓慢拉远（Slow Pull-back / Dolly Out）**：适合孤独扩大、关系疏离、真相后的空落、段落收束或从人物揭示宏观环境。
- **跟拍（Tracking Shot）**：适合行走、追随、工作流程、群体穿行和持续行动；镜头速度由人物运动决定，并利用前景掠过与后景位移形成清晰视差。
- **低角度跟拍（Low-angle Tracking Shot）**：适合逃亡、冲锋、压迫、力量和速度感；机位贴近地面跟随脚步或载具，不用于普通静态对话。
- **低角度仰拍或缓慢上摇（Low Angle / Tilt-up）**：适合权力建立、人物重新站起、体量揭示和英雄性时刻；必须由人物起身、抬头或目标显露触发，避免无依据神化人物。
- **俯拍或鸟瞰（Bird's-Eye View / High Angle）**：适合展示空间秩序、人物渺小、群体调度、路径和地理关系；不承担细腻面部表演。
- **虫视镜头（Worm's-Eye View）**：适合极端压迫、庞大主体、狭窄通道或危险逼近；贴近地面并明确前景纹理、主体路径和压迫来源。
- **航拍或无人机镜头（Aerial / Drone Shot）**：适合建立地域、旅程、战争、自然尺度和史诗空间；亲密文戏只可作为建立或转场镜头，不在对白高潮中突然升空。
- **FPV航拍**：适合穿越、俯冲、追逐和高速空间探索；写清穿越路径、障碍物、加速或抬升节点，避免用于克制静态剧情。
- **主观视角（POV / First-Person Perspective）**：适合恐惧、搜寻、探索、身体体验或关键信息发现；必须明确是谁的视角、可见身体边缘、视线目标和呼吸或动作反馈。关系戏不能全部改成POV。
- **荷兰角（Dutch Angle）**：适合精神失衡、危险、不安和世界秩序倾斜；写清倾斜方向与幅度，只在叙事失衡确实发生时使用，不用于常规谈话。
- **快速变焦推拉（Crash Zoom）**：适合惊吓、荒诞、突发发现、粗粝纪实或类型化喜剧；必须由突发信息触发，瞬间落到明确主体或细节。禁止用于克制悲伤、温柔关系和写实慢节奏场景。
- **希区柯克变焦（Dolly Zoom）**：适合认知崩塌、恐惧、眩晕或真相揭晓；主体画面尺寸大致保持，背景空间产生拉伸或压缩，只用于单一重大心理转折。
- **高速跟拍与动态模糊（High-speed Chase）**：适合赛车、追逐、逃亡和高速动作；主体保持相对清晰，背景沿运动反方向形成动态拖影。禁止用于静态文戏。
- **升格慢动作（Slow Motion）**：适合决定性动作、碰撞、水花、雨滴、落泪错觉或人物主观时间延长；只放慢关键瞬间，不把整段日常动作和完整对白都处理为慢动作。用户没有指定帧率时不擅自写具体数值。
- **延时摄影（Time-lapse）**：适合明确表现长时间流逝、城市昼夜、天气变化和场景演化；不用于要求实时连续表演或同期对白的镜头。
- **匹配剪辑（Match Cut）**：适合跨时间、跨空间或主题联想；前后镜头必须有可说明的形状、动作、方向、色块或构图对应关系。连续关系戏若没有转场需求，不强行使用。

克制文戏、悲伤、亲密关系和现实主义场景，默认优先缓慢推进、缓慢拉远、轻微侧移、关系型跟拍或呼吸感手持。惊悚、恐惧和认知冲击才考虑荷兰角、POV、快速变焦或希区柯克变焦。动作、追逐和速度型场景才考虑低角度跟拍、FPV或高速跟拍。史诗、旅程和宏观空间才考虑航拍、鸟瞰或大幅拉远。

同一短镜头原则上只完成一种主要运动。保持景别相对稳定，不在短时间内从全景直接运动到特写。大幅景别变化通过动作切点、视线切点或声音切点完成。

镜头不能提前预告人物反应。环境声或光线出现后，先呈现人物反应，再调整镜头。人物停止后，镜头可沿原方向继续极短距离完成落幅，但不能无目的漂移。

每个镜头都必须在正文中输出完整运镜描述，不得只在标题写术语。使用以下合同：

```text
运镜手法中文名（English）
+ 选择该手法所服务的剧情情绪或叙事功能
+ 起幅画面的简洁caption与明确起幅景别
+ 前景对象与后景对象
+ 触发镜头运动的人物动作、声音、光线或事件
+ 机位运动方向、路径、速度、幅度和景别变化边界
+ 焦点、主体与背景的可见变化
+ 落幅位置、人物状态与情绪结果
```

例如：`起幅：赵甲第低头站在画左，李枝锦从身后扶住他的肩膀（双人近景）。前景：虚焦缆绳；后景：灰蓝色渔船与雨幕。` 随后再写：“采用缓慢推进（Slow Push-in）；赵甲第停止晃动并睁眼后，镜头才沿两人肩线极缓靠近，移动幅度很小，始终不越过单人近景边界；焦点保持在赵甲第眼睛，李枝锦在后景仍可辨认，最终落在两人关系仍然成立的构图中。”

### 7. 安排环境次级运动与声音

选择少量真实次级运动，如雨滴、涟漪、船只轻晃、树叶摆动、头发和衣角受风、远处车辆灯光。它们负责空间生命和表演触发，不抢主要动作。

声音要有来源和距离变化。环境声持续存在；对白时可降低存在感但不中断。无配乐时明确“无配乐，有真实自然音效”。

### 8. 保持剪辑连续

跨镜头锁定人物身份与服装、湿润或受伤状态、摄影轴线、画面方向、道具所在手与归属、人物接触关系、动作阶段、光线方向、天气、环境声和情绪动量。

连续性锁定身份、方向、动作阶段和关系，不锁定每个关节的精确坐标。允许头部、手臂、手指、重心和接触力度自然微调，禁止机械复刻姿势。

优先使用动作切点、视线切点和声音切点。切镜后承接动作与情绪，不重新开始拥抱、抬头、转身或拿取道具。

## 画质与光影

用户提供风格或测试有效的 GT 时优先保留，不擅自替换。没有明确风格时，根据剧情选择克制的电影摄影表达，不自动堆砌品牌、导演姓名和万能画质词。

【光影】至少明确主光来源、方向、软硬与大致色温，环境填充与光比，人物面部受光，暗部与亮部保留状态，以及天气、实景灯或移动光源对画面的影响。光线变化必须有真实来源，禁止无来源闪烁或突然曝光跳变。

## 反向限定

只写当前场景的高风险问题，优先覆盖：

- 无动机快速推进、甩镜、追焦、追车、环绕和复合运镜；
- 短时间从全景运动至特写，或镜头抢在人物反应前运动；
- 大量孤立特写和关键关系人物消失；
- 僵硬站立、匀速重复动作、瞬间变脸和夸张哭喊；
- 跳轴、动作重启、道具换手、接触点瞬移和肢体穿模；
- 素材污染、人物复制、服装变化和场景闪烁；
- 用户未要求的对白、字幕、旁白、配乐或额外剧情。

不要把每条正向描述都重复改写成负向句。

## 输出自检

输出前确认：

- 固定结构完整且段落职责不重复；
- 每个镜头标题都有明确景别，未用焦段或“关系镜头”代替景别；
- 每个镜头正文都以“起幅：简洁caption（景别）”开头，caption只描述开始瞬间；
- 每个镜头只列前景与后景，没有把“中景”作为空间层级字段；
- 每份使用素材有单一明确职责；
- 每个主要动作有动机、触发和结果；
- 多人镜头包含相互反馈；
- 运镜缓慢、有触发、幅度克制并保持关系构图；
- 已根据剧情氛围、节奏和风格选择运镜，没有为炫技强行调用特殊手法；
- 每个镜头标题标出运镜手法，正文写清适配功能、起幅景别、前景、后景、触发、路径、速度、画面变化与落幅；
- 快速变焦、希区柯克变焦、荷兰角、POV、FPV、高速跟拍、延时和升格只在对应剧情条件成立时使用；
- 关键关系镜头的前景与后景明确，主体和关系写入起幅caption与表演描述；
- 大幅景别变化通过合理切镜完成；
- 台词原文、说话人和闭口聆听状态正确；
- 跨镜头动作、情绪、轴线与接触关系连续；
- 反向限定只覆盖本场主要风险；
- 最终只输出 Prompt 正文。

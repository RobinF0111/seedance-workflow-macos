# Seedance Workflow macOS

Seedance Workflow V4.3.5 Stable for macOS，包含可运行的 macOS 应用与配套技能文件。

## 使用方式

请先阅读 `使用说明.txt`，然后打开 `Seedance Workflow V4.3.5.app`。

## API Key 安全说明

- 仓库不包含任何 OpenAI API Key。
- 使用者需要在应用内配置自己的 API Key。
- API Key 只保存在使用者本机，不应提交到 GitHub 或分享给他人。

## 系统要求

- macOS
- Apple Silicon（当前应用内的可执行文件为 arm64）

# Seedance Workflow for macOS

面向影视创作者、短视频团队、广告制作人与 AI 视频爱好者的 Seedance 专业提示词导演。

Seedance Workflow 将一句创意、剧情梗概、分镜、参考图片或已有提示词，整理为结构清晰、可直接投喂 Seedance 等视频平台的中文影视提示词。产品重点处理人物表演、镜头语言、空间关系、视觉风格与跨镜头连续性，帮助普通用户减少反复修改提示词的成本。

> **产品边界：**本应用生成的是专业视频提示词，不直接连接 Seedance、生成视频或托管成片。用户需要把结果复制到自己选择的视频生成平台。

> 当前稳定版本：V4.3.5 · macOS · Apple Silicon

## 产品能力

- **从零生成提示词**：输入剧情、人物、场景和创作要求，生成完整的 Seedance 影视提示词。
- **六类快速入口**：商品广告、人物短片、剧情短剧、图生视频、MV / 音乐视觉和镜头风格复刻。
- **向导式创作**：先选择发布平台、目标时长、画面比例并写下一句话创意，再按需补充专业细节。
- **优化已有提示词**：在保留原剧情事实与用户指定内容的基础上，完善表演、构图、运镜、光影和连续性。
- **参考素材映射**：明确人物、场景、音频等素材各自承担的职责，降低人物复制、身份混淆和参考污染风险。
- **参考图风格提取**：从参考图片中提炼摄影质感、镜头特征、色彩、曝光与光线关系，不擅自复制图片中的人物或剧情。
- **影视级镜头设计**：为每个镜头明确景别、起幅、前景、后景、人物动作、声音、运镜触发与落幅。
- **连续性控制**：检查人物身份、服装、道具、动作阶段、视线、轴线、天气、光线与声音的跨镜头一致性。
- **语义质量检查**：生成后进行独立审计，识别剧情偏离、不合理动作、镜头执行问题、参考不一致和风格冲突。
- **本地历史记录**：可由用户自行选择本机保存位置；历史内容与 API Key 分开管理。

## 适合谁使用

- 希望快速完成 AI 视频提示词、但不熟悉专业摄影术语的个人创作者；
- 需要把剧本或分镜转化为可执行视频生成指令的导演、编剧和制片团队；
- 需要统一镜头描述规范、人物连续性和视觉风格的广告与内容团队；
- 希望在已有提示词基础上进行专业化完善的 Seedance 用户。

## 系统要求

- Apple Silicon Mac：M1、M2、M3、M4 或后续芯片；
- 当前应用内可执行文件为 `arm64`，暂不支持 Intel Mac；
- 能够访问 OpenAI API 的网络环境；
- 用户自己的 OpenAI API Key；
- 推荐安装 Chrome、Edge 或 Chromium。未安装时，程序会尝试使用系统默认浏览器。

## 安装与启动

> **当前签名状态：**V4.3.5 尚未完成 Apple Developer ID 正式签名与 notarization，因此首次运行可能触发 macOS 安全提示。正式签名与公证已列入路线图；在完成前，不应把本版本描述为“已通过 Apple 公证”。

1. 下载并解压完整的软件包，不要单独移动 `.app` 内部的文件。
2. 双击 `Seedance Workflow V4.3.5.app`。
3. 首次运行若被 macOS 安全机制拦截，请在 Finder 中右键应用，选择 **打开**，再在系统提示中确认。
4. 应用启动后会优先打开 Chrome、Edge 或 Chromium 独立窗口；没有可用的 Chromium 浏览器时，将使用默认浏览器。
5. 在页面右上角打开 API 设置，填写你自己的 OpenAI API Key，并完成连接验证。
6. 如需保存历史记录，根据首次提示选择一个本机文件夹；也可以暂不启用。

## 快速开始

### 1. 选择任务类型

应用提供两种核心任务：

- **生成新提示词**：适合只有剧情、分镜、创意概念或参考素材的场景。
- **提示词优化**：适合已经有 Seedance 提示词，希望在不改变核心内容的情况下提高可执行性与成片稳定性的场景。

### 2. 准备输入内容

为了获得更稳定的结果，建议尽量提供以下信息：

- 人物：姓名或代号、人物关系、外貌与服装要求；
- 场景：地点、时间、天气、环境特征；
- 剧情：事件顺序、开始状态、关键转折和结束状态；
- 表演：人物目标、情绪变化、关键动作；
- 台词：原文及说话人；
- 镜头要求：景别、视角、运镜、节奏或明确禁用项；
- 声音：环境声、音效、音乐或“无配乐”；
- 参考素材：每张图片、视频或音频分别用于人物、场景、风格还是声音。

不需要具备摄影专业知识。只要清楚描述“谁、在哪里、发生什么、希望观众感受到什么”，工作流会补全适合的镜头表达。

### 3. 提交任务

输入内容后提交生成。系统会先建立剧情与素材约束，再设计人物表演、空间构图、运镜、光影、声音和剪辑连续性，最终输出结构化中文提示词。

### 4. 检查结果

建议重点确认：

- 人物身份、数量和关系是否正确；
- 台词是否保持原文，说话人是否正确；
- 参考素材是否映射给了正确的人物或场景；
- 镜头顺序是否符合剧情因果；
- 是否存在你不希望出现的字幕、旁白、音乐或新增剧情。

确认后，将生成结果复制到对应的视频生成平台，并在平台页面单独设置时长、画幅、帧率和分辨率等参数。

## 推荐输入示例

```text
任务：生成新提示词

人物：林夏，28岁，深色风衣；陈默，30岁，灰色西装。两人曾经是搭档。
场景：雨夜的旧火车站，站台空旷，冷白顶灯偶尔闪烁。
剧情：林夏准备上车，陈默从后方追来。两人短暂对视，陈默想挽留但没有说出口。
台词：林夏说：“别再跟来了。”
声音：持续雨声、远处列车广播，无配乐。
风格：克制、写实、冷色电影感，不使用快速变焦或夸张手持。
结尾：林夏上车，陈默留在站台。
```

## 输出内容说明

完整结果通常包含以下部分：

1. **画质与影像风格限定**：整体摄影质感、画面质量和风格边界；
2. **光影**：主光来源、方向、软硬、色温、光比与曝光策略；
3. **人物与场景参考**：参考素材与人物、场景、音色等职责的对应关系；
4. **场景与主要情节**：本场戏的剧情目标、人物关系和情绪变化；
5. **逐镜头描述**：器材语言、焦段、光圈、景别、角度、起幅、前后景、表演、声音、运镜路径与落幅；
6. **表演与剪辑连续性限定**：跨镜头必须保持一致的身份、动作、道具、光线和声音状态；
7. **反向限定**：针对当前场景最容易出现的问题给出明确排除要求。

时长、画幅、帧率和分辨率等平台参数通常不写进提示词正文，请在生成平台中单独设置。

## 内置 Skills

软件包中的 `skills` 文件夹包含三项相互协作的能力模块。每个 Skill 都有独立职责，避免生成、风格处理和质量检查相互干扰。

### `sd-prompt-wip`：影视提示词生成核心

这是主要的提示词编排模块，负责把用户输入转换为可执行的 Seedance 中文提示词。

主要作用：

- 保留人物、关系、场景、道具、事件顺序、台词和故事结果；
- 把抽象情绪转化为视线、呼吸、停顿、重心、接触力度等可观察表演；
- 为每个镜头建立明确的起幅、景别、前景、后景和人物关系；
- 根据剧情选择缓慢推进、拉远、跟拍、主观视角、航拍等镜头手法；
- 写清运镜的触发、方向、速度、幅度、焦点变化和最终落幅；
- 管理人物、道具、动作、轴线、光线、声音和情绪的跨镜头连续性；
- 生成与当前场景相关的反向限定，减少穿模、跳轴、人物复制和无动机运镜。

它适用于“生成新提示词”和“优化已有提示词”两类任务，是整个工作流的内容生产核心。

### `style-constraint`：参考图摄影风格限定

该模块只处理摄影与视觉风格，不负责改写剧情。

主要作用：

- 分析参考图的拍摄质感、镜头特征、透视、构图和空间层次；
- 提炼影调、色彩结构、曝光、主光方向、光线软硬和明暗关系；
- 区分后期调色与真实环境光，减少不合理的有色光源描述；
- 输出可复用的摄影风格与光影限定；
- 保留用户原有的人物、场景、动作、服装、道具和剧情，不擅自替换内容；
- 避免在没有依据时强行加入摄影机品牌、导演风格、胶片规格或特殊镜头。

使用该能力时需要提供至少一张参考图片。没有参考图时，系统不会凭空编造“参考图风格”。

### `seedance-qa-gate`：语义质量审计

这是独立、只读的质量检查模块。它不会直接重写初版，而是判断是否需要修复，并把问题交给对应模块处理。

主要检查：

- 剧情、人物、关系、台词、道具和事件结果是否忠于用户输入；
- 人物行为、因果、反应时机和空间调度是否合理；
- 每个镜头是否描述了能够实际呈现的戏剧动作；
- 运镜是否服务剧情，是否具有明确触发、路径与落幅；
- 人物、服装、道具、视线、方向、天气、光线和声音是否连续；
- 参考人物和场景是否发生身份混合、外观漂移或无依据扩写；
- 风格、光影与剧情是否相互支持，是否存在冲突和生成风险。

审计通过时保留初版；发现明确问题时，会输出可执行的最小修复要求，再由负责生成或风格的 Skill 定向完善。这样可以减少大范围重写带来的内容漂移。

## 三个 Skill 如何协作

```text
用户剧情、分镜、参考素材或已有提示词
                ↓
sd-prompt-wip 建立剧情合同并生成影视提示词
                ↓
style-constraint 根据参考图补充摄影风格与光影限定
                ↓
seedance-qa-gate 独立检查剧情、镜头、连续性与参考一致性
                ↓
如有明确问题，交回对应 Skill 进行最小范围修复
                ↓
输出可复制使用的最终提示词
```

## API Key 与数据安全

- 本仓库和三个 Skill **不包含开发者的 OpenAI API Key**；
- 每位使用者需要配置自己的 OpenAI API Key，并承担对应账户产生的 API 费用；
- API Key 通过应用内的本地设置页面配置，验证后由当前 macOS 系统账户加密保存；
- API Key 不会写入 Skill 文件，也不会保存到用户选择的历史记录目录；
- 不要把 API Key 写进剧情、提示词、截图、日志或提交到 GitHub；
- 如怀疑 Key 已泄露，请立即前往 API 服务商后台撤销并重新创建；
- 历史记录保存位置由用户选择，可能包含输入文本、生成结果和图片，请妥善管理该文件夹及其访问权限。

## Skill 更新方式

应用旁的 `skills` 文件夹用于持续更新能力模块：

```text
skills/
├── sd-prompt-wip/
├── style-constraint/
└── seedance-qa-gate/
```

更新时：

1. 退出正在运行的 Seedance Workflow；
2. 备份现有 `skills` 文件夹；
3. 使用新版同名文件夹完整替换旧文件夹；
4. 重新启动应用并进行一次测试生成；
5. 不要修改 Skill 的目录名，也不要把 API Key 写入 Skill 文件。

## 常见问题

### 为什么必须使用我自己的 API Key？

软件不内置或共享开发者 API Key。每位用户使用自己的 Key，可以独立管理额度、费用、权限和撤销操作。

### API Key 会上传到 GitHub 吗？

不会。本仓库不包含 Key，Key 也不应写入任何 Skill 或项目文件。应用配置的 Key 保存在本机系统账户下。

### 为什么双击应用没有打开？

首次运行可能被 macOS 安全机制拦截。请在 Finder 中右键应用并选择 **打开**。如果设备是 Intel Mac，当前 arm64 版本无法直接运行。

### 为什么需要提供参考图？

`style-constraint` 需要从真实图片中判断摄影、色彩和光影特征。没有参考图时，它不会编造参考图专属的视觉结论。

### 生成结果可以直接使用吗？

结果按可提交提示词设计，但生成前仍建议核对人物、台词、素材映射和剧情结果。不同视频平台的模型版本、内容政策和参数设置可能影响最终效果。

### 如何获得更稳定的结果？

尽量明确人物关系、事件顺序、结尾状态、台词说话人、参考素材职责以及不希望出现的内容。输入越清晰，系统越容易保持剧情与人物连续性。

### 可以在 Intel Mac 上运行吗？

当前版本仅提供 Apple Silicon `arm64` 应用，不支持 Intel Mac。
